【追加内容】
・継続物件・終了物件・保管済み物件の各一覧に「📝 メモ」ボタン
・同じ物件のメモを編集・保存。工事を終了・保管してもメモは維持
・メモ画面の「📄 PDFに出力」は現在の入力内容をPDF化
・PDF化だけではメモ保存されません。必ず「メモを保存」
・保存データの物件オブジェクトに memo を保持し、JSONバックアップに含めます
・メモ自体はWord日報・Excel月報には含めません
・PDFは画像としてページに埋め込むため文字検索・コピーできません

1. アプリ画面で Ver.17.3.16 を確認

3. PDFに物件名・本文・出力日が表示されることを確認
4. 既存のWord日報（赤字機能）とExcel月報が従来どおり出力できることを確認
5. 終了・保管後のメモ保持を確認（本番の物件は不用意に終了させないでください）
